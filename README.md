## ⚙️ Getting Started

To run any code:

1. Clone the repo:
  ```bash
  git clone https://github.com/Vevan05/Machine-Learning.git
  cd Machine-Learning
  ```
2. Install required packages
  ```bash
  pip install numpy pandas matplotlib scikit-learn apyori scipy
  ```
3. Run the scripts
   (Can be done using ```Google Colab``` or ```Jupyter Notebook```)
